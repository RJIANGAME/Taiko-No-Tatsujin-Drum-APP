Taiko Phone Drum release package
================================

Files in this ZIP:
- Taiko-Drum-Menu.bat
- Taiko-Phone-Drum-debug.apk
- scripts needed by the BAT menu
- receiver needed by the Wi-Fi input bridge

Quick start:
1. Install Taiko-Phone-Drum-debug.apk on your Android phone.
2. Double-click Taiko-Drum-Menu.bat on Windows.
3. Choose Start Wi-Fi receiver.
4. Type the shown PC IP into the phone app, keep port 27183, then tap Wi-Fi.

USB mode:
1. Enable USB debugging on Android.
2. Connect the phone by USB and accept the prompt.
3. In Taiko-Drum-Menu.bat choose Setup USB mode.
4. Tap USB in the phone app.

If Taiko no Tatsujin ignores input, use the Administrator receiver option in the BAT menu.
